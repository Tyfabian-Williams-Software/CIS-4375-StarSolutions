# templates Folder
This folder contains Jinja2 HTML templates used for rendering pages.

## Files
- base.html: Base layout extended by all other templates.
- front.html: Interface for front desk staff to create and view orders.
- kitchen.html: Interface for kitchen staff to manage and update order status.
- admin.html: Admin dashboard for managing users and orders.
- login.html / register.html: Authentication pages.
