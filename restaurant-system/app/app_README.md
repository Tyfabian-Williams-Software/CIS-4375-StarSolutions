# app Folder
This folder contains the core application logic.

## Files
- __init__.py: Initializes the Flask app, database, login manager, and socket connections.
- models.py: Defines database models (User, Order, etc.).
- auth/: Handles authentication (login, registration, logout).
- routes.py: Defines main routes for front and kitchen roles.
- admin.py: Contains CRUD operations for the admin dashboard.
- sockets.py: Initializes Flask-SocketIO and event broadcasting functions.
